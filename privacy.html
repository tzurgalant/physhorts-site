Privacy policy

Last updated: October 16, 2026

physhorts is a personal tool used by a single person, the owner of one YouTube channel, to upload videos that the tool generates itself. This page explains what it does with data.

YouTube API Services

physhorts uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data it accesses

  • With the channel owner's permission (Google OAuth), it uploads and schedules videos, updates their titles, descriptions and thumbnails, lists the channel's recent uploads, and reads view counts and average view percentage for those videos.
  • It accesses only the owner's own channel. It does not collect, store or process information about viewers or any other person.

How data is stored

  • The OAuth refresh token is kept as an encrypted GitHub Actions secret and in a local file on the owner's computer. It is never published or shared.
  • Video statistics (views and average view percentage per video) are saved in the owner's private repository and used only to choose which kinds of videos to make next.
  • No data is sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time on the Google account third-party access page. Stored statistics are deleted on request, and stored tokens are deleted when access is revoked.
